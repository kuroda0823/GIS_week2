# GIS 公園の少ない地帯分析シミュレーター

岡山市内の『公園過疎地』をあぶり出して、  
「新しい公園作ったらどれくらいハッピーになるか」を数字で分析できるシミュレーター

---

## 📋 概要

1. **どこら辺が公園少ないか秒でわかる**
   - 地図見てるだけだと「この辺、公園少なくね？」しかわからんが、このアプリは基準から外れてる場所を「赤い点」にしてくれるから一目でわかる。
   
2. **シミュレーションで結果がすぐ出る**
   - 赤い点が集まってる中をクリックすると仮想の公園(赤いピン)が作られて、どんくらいハッピーにできるか、何％改善されたかを自動で計算してくれる

3.**どっちがいいかわかる**
   - シミュレーションの結果を見て、「A地点よりB地点のほうが何％高い」っていうのがすぐわかるからめっちゃいい場所に公園作れる

---

## 必須機能

**01 エリアにサンプル点を生成**   
指定したエリア(四角)の中にだけ、200mおきに点を敷き詰める  
   
**02. 一番近い公園を探す**  
それぞれのドットから「一番近い公園」を見つける  
エリアの外にある公園も候補に入れて探す

**03. 距離のハードルを変えられる**  
公園まで300m・500m・1000m」の3パターンで、どれくらいなら圏内かをプルダウンで切り替えて、点数を計算し直せる

**04. 見た目で一発でわかるようにする**  
公園のパワーが届く範囲を円で書いて、点もセーフかアウトか色分けする！  
「この色は何だよ〜」っていう説明（凡例）もちゃんと画面に出す！

**05. 仮想公園1か所の追加とリセット**  
エリア内好きなとこに「仮の公園」を1個だけ置いて、「置く前と後でどんだけ良くなったか」を比べる  
リセットもできる

**06. 結果をセーブできる**  
「ここだ！」ってなった時の設定と結果を、丸ごとダウンロードできる  
後で「あの時のあれ」って全く同じ状態をすぐ復活できる

3. 公園の設備・規模属性データ
   - 単に「公園があるか」だけでなく、遊具・広さ・ターゲット層（遊具公園・運動公園等）に応じたサービス圏の設定。
