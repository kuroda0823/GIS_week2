# GIS 公園の少ない地帯分析シミュレーター

岡山市内の『公園過疎地』をあぶり出して、  
「新しい公園作ったらどれくらいハッピーになるか」を数字で分析できるシミュレーター

---

## 📋 概要

1. **どこら辺が公園少ないか秒でわかる**
   - 地図見てるだけだと「この辺、公園少なくね？」しかわからんが、このアプリは基準から外れてる場所を「赤い点」にしてくれるから一目でわかる。
   
2. **シミュレーションで結果がすぐ出る**
   - 赤い点が集まってる中をクリックすると仮想の公園(赤いピン)が作られて、どんくらいハッピーにできるか、何％改善されたかを自動で計算してくれる

3.**どっちがいいかわかる**
   - シミュレーションの結果を見て、「A地点よりB地点のほうが何％高い」っていうのがすぐわかるからめっちゃいい場所に公園作れる

### 1. リポジトリのクローン

# 公園から遠い地点を調べる分析マップ

公園の配置計画を、地図上の空間分析を用いて評価・シミュレーションするツールです。

## 概要と主な機能

〇ドット（サンプル点）による住民の可視化  
   対象エリアの地図上に等間隔でサンプル点を配置します。  
〇空白地帯（公園難民エリア）の特定  
   既存の公園から一定の距離圏（例: 半径500m）を計算し、公園圏内の点と公園圏外の点を色分けして可視化します。  
〇新規設置のシミュレーションと効果測定  
   圏外の点が密集しているエリアに「仮想の公園ピン」を配置すると、新たな距離圏が再計算されます。  
   これにより、状況の変化を視覚的かつ定量的に比較できます。  

## 解決する課題

「この辺りに公園が足りない気がする」という感覚的な意見を排除します。
地図上の点データの増減を計算することで、「ここに公園を新設すれば、エリアのカバー率が〇〇%向上する」という客観的なエビデンスに基づく立地選定を可能にします。

## 必須機能

**01 固定エリアにサンプル点を生成**   
約200m間隔を基準とし、Polygon内・境界上だけを対象にする。  
   
**02 最寄り公園と距離**  
エリア外の公園を含む入力データ全体から探索する。  

**03 距離圏の切替**   
300m・500m・1,000mで、点の分類と集計を切り替える。  

**04 距離圏の可視化**  
バッファと点の分類を表示し、凡例で読み取れるようにする。 

**05 仮想1か所の追加とリセット**  
追加前後の差を同じ点集合で比較する。  
   
**06 結果と条件の保存**  
GeoJSONとパラメータJSONを出力し、同じ結果を再現できる。
